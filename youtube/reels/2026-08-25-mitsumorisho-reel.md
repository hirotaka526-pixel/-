# リール台本(ネタ帳)|「見積書のここだけ見て」

- チャンネル: 1級建築士 まえちゃんの家づくり教室
- 出演: まえちゃん(解説) × 川下さん(視聴者代弁)
- 尺: 75〜85秒(上限90秒)
- 目的: ロング動画への導線 + 保存されるリール
- 想定視聴者: 1〜2社から見積を取り始めた/これから比較する人
- **この1本で言うことは1つだけ**: 「見積書は合計金額より先に、"一式"の数と"別途工事"欄を見る」

---

## 1. research(事実確認メモ)

| 項目 | 扱い |
|---|---|
| 「一式」表記・「別途工事」欄 | 制度ではなく業界の商習慣。年度で変わる情報ではないので、断定して話してOK |
| 諸経費・仮設工事の一式表記 | 業界的に普通。「一式は全部悪」と言うと不正確なので、必ず線引きを入れる |
| 構造計算・省エネ計算・申請関係の費用 | 2025年4月施行の建築基準法改正(いわゆる4号特例の縮小)で、木造2階建て等でも確認申請時に構造・省エネ関係の図書提出が必要に。これに伴い、見積書に構造計算費・申請費が明記されるケースが増えている |
| その費用の金額感 | 業界団体試算として1棟20〜40万円程度と報じられているが、会社・規模で幅が大きい。**リール内で金額は断定しない**。触れるなら「うちの地域・うちの規模だとこれくらい」と自社実感ベースで一言だけ |

公開前に再確認が必要な箇所: 金額に言及する場合のみ(上記)。それ以外は再確認不要。

---

## 2. title(キャプション冒頭・タイトル案)

| 案 | 軸 |
|---|---|
| ① 見積書、合計金額から見てる人は損してます | 損失回避 |
| ② **1級建築士が見積書で最初に見る2か所** | 権威性 + 具体性 |
| ③ 「一式」が多い見積書、気をつけてください | 損失回避 + 具体性 |
| ④ 安い見積書ほど「別途工事」が多い理由 | 意外性 |
| ⑤ 打ち合わせ前に見て。見積書のチェックポイント | 実用性 |

**推奨: ②**
理由: 「2か所」と範囲が閉じているので最後まで見る動機になる(完視聴率が上がる)。さらに"1級建築士が"が入ることでロング動画への導線としての権威性も担保できる。①③は煽りに寄りやすく、リール単体では強いがチャンネルの型(中立・本音)とはやや相性が悪い。

## 3. structure(尺配分)

| パート | 尺 | 内容 |
|---|---|---|
| つかみ | 0〜8秒 | 結論先出し。名乗り・チャンネル説明は入れない |
| ①「一式」の数を数える | 8〜45秒 | 結論→理由→具体例→線引き |
| ②「別途工事」欄を先に読む | 45〜70秒 | 結論→理由→オチ |
| まとめ + CTA | 70〜85秒 | 一言再提示 + 保存促し + ロング動画へ |

論点は2つが上限。3つ目(坪単価の話、値引き交渉の話など)を入れたくなっても**別の1本に回す**。

---

## 4. ネタ帳本体

### つかみ(0〜8秒)
- 話す順番:
  1. 川下さんが見積書の実物を持って切り出す →「これ、合計金額だけ見てハンコ押しちゃダメなんですか?」
  2. まえちゃん即答 →「ダメです。合計より先に数えてほしいのは"一式"って書いてある行の数」
- 川下さんに振るポイント: 冒頭の疑問そのものを川下さんに言わせる(まえちゃんの説明から始めない)
- 使いたいキーワード: 合計金額、一式
- 尺: 8秒
- テロップ: **「合計金額から見るな」**
- 注意: 前置きゼロ。挨拶・自己紹介を入れた時点で離脱する

### ①「一式」が危ない理由(8〜45秒)
- 話す順番:
  1. 結論: 「一式」は"何がどこまで入っているか分からない"欄。後から「それは含んでません」が起きるのはだいたいここ
  2. 理由: 数量と単価が書いてないので、他社と比較もできないし、交渉もできない
  3. 具体例(あくまで例として言う): 「電気工事 一式 ◯◯万円」→ コンセント何個・照明何個までなのかが書かれていない。着工後に「1か所追加ごとに◯円」と請求されるパターン
  4. **線引き**: ただし諸経費・仮設工事の一式は業界的に普通。全部の一式に噛みつく必要はない
- 川下さんに振るポイント: 「じゃあ一式って書いてあったら全部アウトなんですか?」→ ここでまえちゃんが4.の線引きを話す。**ここが信頼構築の肝**(全否定しない)
- 使いたいキーワード: 一式表記、数量と単価、内訳明細、追加費用
- 尺: 35秒前後
- テロップ: 「"一式"=何が入ってるか不明」/「比較も交渉もできない」
- 注意: 金額は「例えば」と明示して言う。実在の見積と誤解されないように

### ②「別途工事」欄を先に読む(45〜70秒)
- 話す順番:
  1. 結論: 合計金額の下にある小さい字の「別途工事」「本体工事に含まれないもの」を先に読む
  2. 理由: 地盤改良・外構・カーテン・照明・エアコン・給排水の引込…ここが全部別途だと、最終的な総額が数百万単位で変わる
  3. 一言で締める: 「安い見積書ほど、別途が多い」
- 川下さんに振るポイント: 「え、そこ一番小さい字で書いてあるとこじゃないですか」→ まえちゃん「そう。**一番小さい字が、一番お金かかります**」
- 使いたいキーワード: 別途工事、本体工事、地盤改良、外構、総額
- 尺: 25秒
- テロップ(オチ): **「一番小さい字が一番高い」**

### まとめ + CTA(70〜85秒)
- 話す順番:
  1. 一言再提示: 「合計金額の前に、"一式"の数と、"別途工事"欄」
  2. 保存促し: 「打ち合わせの前に見返せるように保存しておいてください」
  3. ロング導線: 「見積書は本編で1枚ずつ実物を見ながら解説してるので、プロフィールから見てください」
- 尺: 12〜15秒
- 注意: **自社(インザホーム)への問い合わせ誘導は入れない**。1本目から営業色を出すとリールは伸びないし、チャンネルの中立性が崩れる

### 撮影メモ
- 実物の見積書(サンプルでよい・社名は伏せる)を手に持ち、「一式」の行を指でなぞる。この画があるかどうかで完視聴率が変わる
- 無音視聴前提。全カットにテロップを入れる
- 画面下20%と右端はUIで隠れるので、テロップは上〜中央に置く

## 5. thumbnail(カバー画像・冒頭テロップ文言)

| 案 | 狙い |
|---|---|
| A「合計金額から見るな」 | 損失回避。短く強い。**冒頭0.5秒のテロップに推奨** |
| B「一番小さい字が一番高い」 | 意外性。**カバー画像に推奨**(オチを先出ししても中身が気になる型) |
| C「"一式"に注意」 | 即読めるが引きが弱い。サブコピー向き |

- **推奨: カバー=B / 冒頭テロップ=A**
- サブコピー: 「見積書チェック 2か所」
- レイアウト方針: まえちゃんが見積書を手に持ったバストアップ。上1/3に白背景・赤文字で大きくメインコピー、顔は中央。下20%は空ける(UI被り)
- 役割分担: カバー(B)で「え、なんで?」を作り、キャプション冒頭のタイトル②「1級建築士が見積書で最初に見る2か所」で内容を補足する関係になっている

## 6. review(セルフチェックと指摘)

指摘 → 理由 → 対応、の順で。

1. **論点2つは85秒の上限ぎりぎり**
   → 撮ってみて90秒を超えるようなら、②を丸ごと切って①だけの単発リールにする。②「別途工事」は単体で1本成立する強いネタなので、無理に同居させるより2本に分けたほうが完視聴率・本数の両方で得。
2. **金額の断定を避けている**
   → 電気工事の例・構造計算費とも「例えば」ベース。ここを実額で言うと地域差・規模差でクレームの種になる。
3. **「一式は全部ダメ」と言い切らない構成にしてある**
   → 諸経費・仮設の一式は商習慣として普通。全否定は不正確で、同業からの反発も招く。①の4.の線引きは削らないこと。
4. **ポジショントーク回避**
   → CTAを自社問い合わせではなくロング動画へ振っている。目的(ロング導線)とも一致。
5. **掛け合いのバランス**
   → 3か所で川下さんが入る(冒頭の疑問、一式への突っ込み、小さい字への突っ込み)。一方通行の解説になっていない。
6. 削るとしたらどこか
   → ①の具体例は「電気工事」1つで十分。「じゃあ給排水も…」と2つ目を足したくなるが、リールでは確実に間延びする。

## 7. publish(投稿時チェック)

- キャプション1行目 = タイトル②「1級建築士が見積書で最初に見る2か所」
- キャプション本文: リールで言い切れなかった補足を2〜3行 + 「本編はプロフィールのリンクから」
- 固定コメント: ロング動画へのリンク(リールのキャプション内リンクは踏まれにくい)
- ハッシュタグ案: #家づくり #注文住宅 #見積書 #家づくり計画中 #マイホーム計画 #1級建築士 #住宅ローン #新築一戸建て
- 投稿後のPDCA観点: 視聴維持率が落ちる秒数(8秒前後か、45秒前後か)を確認。8秒で落ちる=つかみの問題、45秒で落ちる=①が長すぎる。次回の尺配分に反映する

# LPチェックスキル(lp-check)

このフェーズの仕事は「良い指摘をすること」であって、「問題なしと言うこと」ではない。
まえちゃんは肯定するだけのアシスタントを求めていない。弱い部分があれば遠慮せず指摘してから、
直し方まで提案する。

## チェック対象

`lp/<slug>/03-copy.md`(コピー段階)、または`lp-builder`が`design`スキルで組み上げた
Canvas/HTML(完成段階)のどちらかを渡される。両方読めるなら両方読む。完成段階のチェックでは
実際の見え方(改行位置・ボタンの目立ち方)も見る。

## チェック項目

### 1. 訴求の一貫性
`01-research.md`→`02-structure.md`→`03-copy.md`で言っていることが繋がっているか。
特に以下のズレが起きやすい:
- ファーストビューのキャッチコピーと、最終CTA直前で言っていることが違う
- 「住宅会社とケンカする必要はない」というスタンスが、途中で業界を過度に敵視する
  トーンに変わっていないか

### 2. 誇張・断定表現
- 「必ず」「絶対」「100%」など、根拠のない断定・効果保証になっていないか
- reel-scriptの原則と同じく、断定しすぎている箇所には**一番反発が来そうな1点にだけ**
  短く逃げ道を入れる(例:「もちろん〜まで、うるさく言う必要はないよ」)。LP全体に
  免責を散らばらせると説得力が薄まるので、入れる場所は絞る

### 3. 数字の裏取り
- `03-copy.md`に出てくる数字・実績が、すべて`01-research.md`(=確認済みの出典)に
  ある数字と一致しているか。ライティング段階で丸められたり誤変換されたりしていないか
- 法改正・補助金・金利など変わりやすい数字は、公開直前の最新状態か再確認する
  (reel-scriptと同じ注意: 年度で変わる制度は特に)

### 4. 特定できる書き方になっていないか
- お客様の声・相談事例から、氏名・地域・住宅会社名が特定できる要素が残っていないか
- 特定の住宅会社が名指し・推測可能な形で批判されていないか(信用毀損リスク)

### 5. 法的表記・信頼要素
- 申込み・料金が絡むLPなので、特定商取引法に基づく表記(運営者情報・連絡先・
  返金や中途解約の条件など)やプライバシーポリシーへの導線があるか
- ここが埋まっていない/`02-structure.md`で「要確認」のままなら、**チェックの結果として
  「公開不可、法的表記の確定が必要」と明記する**。曖昧なまま公開可にしない
- 会社名(インザホーム)・代表者名・資格(1級建築士)などの表示に誤りがないか

### 6. スマホでの見え方
- LPの大半のアクセスはスマホ想定。1文が長すぎて折り返しが不自然な箇所がないか
- CTAボタンがファーストビュー・セクション区切り・最終盤の複数箇所にあり、
  スクロールしても迷わず申し込めるか
- 画像やアートボードの余白・文字サイズがスマホ幅で潰れていないか(Canvas/HTML完成後の
  チェック時に見る)

### 7. CTA導線の一貫性
- LP内の全てのCTA(ボタン・リンク)が同じ申込み先(LINE公式など)を指しているか
- ボタン文言がバラバラで、どれが「本命」の行動か分かりにくくなっていないか

### 8. 誤字脱字・表記ゆれ
- 「インザホーム」「1級建築士」などの固有表記が統一されているか
- 敬体・常体が意図せず混在していないか(まえちゃんの文体は多少混ざってよいが、
  同じ段落内で急に崩れるのは違和感になる)

## 出力フォーマット

`lp/<slug>/04-check.md` に、重大度付きの指摘事項リストとしてまとめる:

```markdown
# LPチェック結果: <サービス名> (<slug>)

対象: lp/<slug>/03-copy.md (または完成Canvas/HTMLのURL)

## 重大(公開前に必ず直す)
- [セクション名] 指摘内容 → 修正案

## 中(直したほうがよい)
- ...

## 軽微(お好みで)
- ...

## 総合判定
公開可 / 公開不可(理由: ...)
```

「重大」が1件でもあれば、総合判定は必ず「公開不可」にする。特に法的表記の欠落と、
特定できてしまう書き方は、指摘だけで終わらせず「これは絶対に直してから公開してください」
と明言する。

## 次に渡すときの注意

`lp-builder`はこの結果を見て、`lp-writing`に差し戻すか、そのまま`design`スキルでの
Canvas化に進むかを判断する。「重大」が残ったまま公開フェーズに進まない。

# ストーリーズ投稿案スキル(story-plan)

## 目的

フォロワー約3,400人のアカウントで、ストーリーズの**閲覧率20%(約680人)**を目指す。
そのために、毎日「そのまま作れる」ストーリーズ1セットを提案する。

## 手順(毎回この順番)

1. **前提を読む**
   - `references/research.md`(閲覧率・完走率を上げる原則。必ず読む)
   - `stories/log.md`(本人が書いた実績の数字。あれば必ず読み、良かった型・悪かった型を反映する)
   - `stories/`の直近7日分の提案(テーマ・型がかぶらないようにする)
   - `reels/`の日付が新しい台本数本(今出しているリールと連動させるため)
   - 数字・技術的な主張を書くときは`.claude/skills/reel-script/references/maechan-facts.md`を読む。
     ここにない数字は使わない。
2. **今日のリサーチ(WebSearch 2〜3回)**
   - ストーリーズ運用の新しい情報(新機能・アルゴリズム・成功事例)を1回以上調べる。
   - 季節・時事の家づくりネタ(例: 11月なら寒さ・結露・年末の補助金)を1回調べる。
   - 新しく分かったことは`references/research.md`の「追記ログ」に、日付と出典URLつきで1〜3行追記する。
     怪しい記事(出典なし・内容の重複したまとめサイト)は使わない。
3. **曜日の型を決める**(下の表。祝日でも同じ型でよい)
4. **投稿案を書く** → `stories/YYYY-MM-DD.md`(日付は日本時間の投稿日)
5. **コミットしてpushする**

## 曜日ごとの型(毎日見に来る理由を作る)

| 曜日 | 型 | 使うスタンプ |
|---|---|---|
| 月 | 家づくりクイズ(2択→答え→理由) | クイズ |
| 火 | 現場・打ち合わせの裏側(動画中心) | 絵文字スライダー |
| 水 | 質問箱の回答(前の週に集めた質問) | 質問箱 |
| 木 | どっち派?アンケート(間取り・設備) | アンケート |
| 金 | 相談であった実例・失敗談(個人が特定できない形で) | アンケート |
| 土 | 施工事例のビフォー/アフター・こだわりポイント | 絵文字スライダー |
| 日 | 今週のまとめ+来週の予告+質問箱で質問を集める | 質問箱 |

`stories/log.md`で特定の型の数字が明らかに良い(悪い)と分かったら、曜日表より数字を優先してよい。

## 1セットの作り方(research.mdの要点)

- **4〜7枚**。10枚は超えない。
- **1枚目**: 1〜2秒で何の話か分かる一言+スタンプ。「答えは次」で続きを見させる。
- **1枚に1メッセージ、文字は3行まで**。
- **最低1枚は動画**(まえちゃんの顔出しトーク15秒、現場の様子など)。
- **最後の1枚**: 質問箱 か 明日の予告(「明日、答え合わせ」など)。
- リールと連動する日は「リールの告知」を1枚入れてよいが、シェアするだけにしない。一言+スタンプをつける。
- 特定の会社・個人が分かる書き方はしない(reel-scriptスキルと同じルール)。
- 口調はリールと同じ、まえちゃんの話し言葉(「〜なんだ」「〜だよね」)。

## 出力の形(stories/YYYY-MM-DD.md)

```
# YYYY-MM-DD(曜) ストーリーズ投稿案

## 今日の狙い
- 型: ○○ / 連動するリール: ○○(なければ「なし」)
- 狙う指標: 閲覧率 or 完走率 or 反応率(1つだけ)
- なぜこの内容か: 1〜2行(リサーチ・ログからの根拠)

## 投稿時間
- おすすめ: ○時ごろ(理由1行)

## 1枚ずつの内容
### 1枚目(静止画 or 動画○秒)
- 画面の文字: (3行まで、そのまま使える文言)
- 背景・素材: (何を撮る/何の写真を使う)
- スタンプ: (種類と、選択肢の文言そのもの)
### 2枚目 ...
(最後まで)

## 動画で話すセリフ(動画の枚がある場合)
(そのまま読める15秒程度の話し言葉)

## 投稿後に見る数字
- 1枚目のリーチ ÷ フォロワー数 = 閲覧率(目標20%)
- 離脱・「次へ」が多い1枚はどれか
- `stories/log.md`に1行書いてもらえれば、明日の提案に反映する

## 今日のリサーチメモ
- (調べた内容を2〜3行。出典URLつき)
```

## stories/log.md の形(本人が書く)

```
| 投稿日 | 型 | フォロワー | 1枚目リーチ | 最後のリーチ | スタンプ反応 | メモ |
```

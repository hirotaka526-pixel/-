# メンバーシップ記事(会員限定)

無料記事とは別物。**「ここでしか読めない」を毎月成立させ続ける**ための設計と型。
会員限定の記事を書くときは、書き始める前に必ずこれを読む。

## 前提(2026-08-31 本人と決定)

- 価格: **月1,000円**
- 更新: **月2〜4本**
- 出す内容: **他社の見積書・図面の実物添削** と **業界の内部ルール**
- 限定にする理由: **同業に読まれると角が立つから**
- 看板記事(1本目): **ZOOM無料相談で実際にあった相談と、その場で出した解決策**

### 3つの導線の役割

| | 無料note | メンバーシップ | 伴走サポート |
|---|---|---|---|
| 役割 | 検索から見つけてもらう | 閉じた場で本音を出す | 本命の商品 |
| 中身 | 判断基準・手順 | 実物の添削・内部ルール | 個別の伴走 |
| 読者 | 検討を始めた人 | 契約前で本気の人 | 決めて動く人 |

**メンバーシップは伴走サポートの下位互換ではない。** 「個別相談はまだ早いが、他人の実例から学びたい」
という層を受け止める場所。ここで信頼が溜まった人が伴走サポートに来る。

### noteの手数料(2026年8月時点)

メンバーシップのプラットフォーム利用料は**10%**(定期購読マガジンの20%とは別)。
これに決済手数料(クレカ5%など)がかかる。月1,000円なら手取りはおよそ855円。

## 毎回の型:「相談カルテ」

会員記事は読み物ではなく **カルテ** にする。毎月同じ型で出すことで、
「今月も1件、他人の家の実例が読める」という価値が積み上がる。

**① 限定の理由(2〜3行。毎回書く)**
「この話は無料の記事には書けません。同業が読める場所で書くと角が立つからです」と、
なぜ閉じた場所なのかを最初に明示する。これが会員であることの意味を毎回思い出させる。

**② 相談の入り口(匿名化した状況)**
どんな方が、どのタイミングで、何に困って相談に来たか。属性は粗く、状況は具体的に。

**③ 相談者の言葉**
実際に言われたセリフをそのまま。「もう契約しちゃったんですけど」のような一言が、
読者に自分を重ねさせる。

**④ 私が最初に見た場所**
**ここが会員記事の核心。** 見積書や図面を渡されて、プロが最初にどこを見るか、その順番。
無料記事は「何を聞くか」までしか書けないが、ここでは「どう読むか」を出せる。

**⑤ 見つかった問題(1〜3つ)**
実際の記載を引用する形で。金額は丸め、社名は伏せる。

**⑥ その場で出した解決策**
言った言葉、書き直させた項目、優先順位。**読者が真似できる粒度**まで下ろす。

**⑦ その後どうなったか**
分かる範囲で。分からないなら「その後は聞けていません」と正直に書く。

**⑧ あなたの家に当てはめるなら**
読者が自分の資料で同じ確認をするための3ステップ。ここがないと他人事で終わる。

**⑨ 会員向けの締め**
無料記事の定型CTA(18大特典/伴走サポート/公式サイト)は**使わない**。代わりに:
- 「見てほしい資料がある方は、コメントかメッセージで送ってください。次回のカルテで扱います」
- 次回予告を1行
- 伴走サポートは押し売りしない。触れるなら最後に1行だけ

分量は無料記事より短くてよい(**2,000〜3,000字**)。会員は結論を求めている。前置きは要らない。

## ネタ元:Googleドライブの相談録

- **`相談：M.D　◯◯様`** という名前のドキュメントが、Googleドライブに18本以上ある
  (2026年5月〜)。ZOOM個別相談の**音声自動要約**
- **`リールネタ帳バンク：個別相談18本から抽出`** — 18本を論点別に集計した一覧。
  出現回数と、使うときの注意・確認メモ付き。**まずこれを読むと全体像が早い**

### 相談録を使うときの注意

- **音声の自動要約なので、固有名詞と数字に誤変換がある**(本人がネタ帳バンクに明記)。
  実際、桁が明らかにおかしい金額が複数ある。**数字は必ず本人に確認してから記事に書く**
- 話者名が「iPhone15」「Naoko」のように端末名や下の名前になっていることがある
- 要約には**相談者の私的な事情**(家族の借金、夫婦間の温度差など)が入っている。
  記事化のときは、その相談の主題に関係ない私的事情を**一切持ち込まない**
- 会社名(ハウスメーカー・工務店)が実名で入っている。**必ず伏せる**

## 匿名化ルール(絶対に守る)

実例を扱う以上、ここを外すと一発で信用を失う。**判断に迷ったら書かない。**

- **本人の許可を取る。** 「事例として書いていいですか」を必ず確認してから記事にする
- **会社名・商品名・営業担当の名前は出さない。** 「大手」「地元の会社」までにする
- **エリアはぼかす。** 「県内」「隣県」程度。市町村名は出さない
- **金額は丸める。** 10万円単位。特徴的な端数は特定につながる
- **家族構成は粗く。** 「30代のご夫婦」まで。子どもの人数・年齢・職業は書かない
- **図面は全体を出さない。** 部分だけ、またはトレースし直したものを使う
- **複数の相談を混ぜて1件に見せない。** どうしても混ぜるなら
  「複数の相談をまとめた事例です」と本文に明記する
- **時期をずらす。** 「先日」ではなく「少し前に」。直近の相談者が特定されないように

## 無料記事との出し分け

同じネタでも、線はここで引く。

- 無料に書けるもの: 判断基準、聞くべきセリフ、制度の説明、一般的な相場
- **会員にだけ書けるもの: 実物の資料に何が書いてあったか、プロが読む順番、
  同業のやり方への具体的な指摘、交渉が実際にどう転んだか**

**無料記事の焼き直しを会員記事にしない。** 一度でもやると解約される。
逆に、会員記事で反応が良かったテーマは、**判断基準の部分だけを無料記事に落として入口にする。**

## 続けるための運用

- 相談が終わったら、その日のうちに **匿名化したメモ** を残す(状況・言葉・見た場所・解決策)。
  記事化はあとでいい。メモがないと、月2〜4本は続かない
- ネタが薄い月は、無理に実例を作らず **業界の内部ルール** の回に振り替える
- 会員から送られた資料を扱うときは、**必ずその人の許可を取る**

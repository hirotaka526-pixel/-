## 2026年8月確認

### 建築基準法 2025年4月施行の改正

- いわゆる **4号特例の縮小**。これまで木造2階建ての確認申請で省略されていた
  構造関係規定の審査が、原則として必要になった
- 対象の区分が「新2号建築物」「新3号建築物」に再編された。一般的な木造2階建ては新2号にあたり、
  構造関係の図書提出・審査が必要。新3号(木造平屋・延べ200㎡以下)は審査省略が残る
- **必要壁量の基準も見直された。** 「軽い屋根 / 重い屋根」の区分をやめ、建物・屋根・外壁・
  太陽光発電設備などの実況に応じて必要壁量を算定する方式になった。断熱材の厚みや
  太陽光パネルで住宅が重くなったことが背景
- **注意:** 義務化されたのは構造計算書の提出と審査であって、耐震等級3にすることではない。
  建築基準法が求めるのは耐震等級1相当のレベルで、等級1の家は合法

### 耐震等級

- 耐震等級は品確法にもとづく住宅性能表示制度で **等級1・2・3の3段階**。
  「等級3相当」という区分は制度上存在しない
- 耐震等級3を出す計算方法は **性能表示計算(品確法)** と **許容応力度計算**。
  建築基準法の壁量計算だけでは等級3は取れない
- 性能表示計算より許容応力度計算のほうが検討項目が多く、必要な耐力壁の量も多くなる
- **未確認:** 「性能表示計算の等級3は強度1.9〜2.0、許容応力度計算は2.4〜2.7」という数字が
  複数の住宅会社サイトに出ているが、一次資料まで辿れていない。**記事に数字として書かない。**
  本人が根拠を持っているなら、確認した上で使う

### 地震保険・性能評価書

- 耐震等級3で **地震保険料が50%割引**(等級2は30%、等級1は10%)
- 割引を受けるには保険会社に **確認資料** の提出が必要。建設住宅性能評価書、設計住宅性能評価書、
  長期優良住宅の認定通知書＋設計内容説明書、フラット35の適合証明書など。
  **「等級3相当」では確認資料が出せないので割引を受けられない**
- 住宅性能評価書の取得費用は **10万〜40万円程度**(書類作成と申請。会社と申請先で変わる)

### 見積書の内訳(2026-09-03 本人インタビュー。**全媒体でこの数字を使う**)

30坪前後の木造2階建てが前提。**「削られやすい項目」は本人が「分からない」と回答したので書かない。**

**金額が膨らみやすい項目**

1. **地盤改良** — 間取り確定後に地盤調査 → 地耐力で工事が決まる。
   地盤の強さ / 地質 / 家の大きさで変わる。**契約時点では誰にも金額が分からない。**
   金額は 数十万円〜200万円(既出)。上限の目安だけ先に聞く
2. **基礎工事の残土処分** — 家の大きさ、既存地面の高さと設計地盤面の設定で変わる。
   **土は掘ると体積が増える**ので、見積の数量は掘る前の体積より多めに計上される(水増しではない)
3. **外壁** — 面積が大きいので、㎡単価の差が積み上がる。**㎡単価を出してもらう価値がある**
4. **窓(サッシ)** ★本人の一番の主張
   - 多くの会社が樹脂サッシ＋トリプル。**掃き出しのような大きな窓では非常に高い**
   - 大きな窓は南側にある → 枠の太い樹脂サッシ＋トリプルだと**冬の日射取得熱が使えない**
   - 高い金額を払っているのに省エネ効果が出ない。掃き出しは**開閉が重たい**
   - 本人の推奨: 南側=アルミ樹脂複合＋ペアガラス / その他=樹脂サッシ / 余裕があればトリプル
   - アルミ樹脂複合を南に使う理由: 枠が細くガラス面積が大きい / 冬の日射取得で暖房費が下がる /
     アルミ枠で軽く掃き出しに向く。外がアルミ、中が樹脂
5. **住宅設備** — **グレード1段階で20〜30万円。表面の仕上げ材(面材)でさらに10〜15万円。**
   キッチンは 高性能IH / フロントオープン食洗機 / 浄水器付き水栓 で積み上がる。
   **トイレ: タンクレス30〜40万円、タンク付き10〜15万円。使い勝手はほとんど変わらない**
6. **内装の壁の仕上げ** — エコカラットやタイルで上がる。
   代案: **外壁用のサイディングを内装に貼る**と質感が出てコストダウンになる

**「一式」で後から追加が出やすい項目(金額の大きい順)**

1. **付帯工事 一式** — 定義がなく中身が会社ごとにバラバラ(屋外給排水を含む会社もある)。
   明細が曖昧なまま**一式300万/400万**の決め打ちが多い。
   **家を小さくしても金額が変わらない** → 小さい家ほど総額に対する重みが大きい
2. **電気工事 一式** — 位置移動・追加という小さな追加が積み重なる。
   スイッチ/コンセントの形状は1つは小さいが**数が多い**。照明1つ増やすと配線とスイッチが要る
3. **内装工事 一式** — 床材と壁天井クロスだけのことが多い。**カーテンとカーテンレールが入っていない**
4. **外構工事 一式** — 境界ブロック・フェンス・造成まで含むことも。造成と外構をまとめる会社もある。
   駐車場(コンクリート/砂利)、アプローチ(コンクリート/レンガ/枕木)、
   **機能門柱 普通20〜30万円・いいもの50〜60万円**、フェンス(高さ・種類で変わる。
   **境界60mならm単価が小さくても大きな金額**)。→ メーカー・商品・品番・単価まで聞く

**契約後の追加工事**

- **インザホームは100万円前後まで**(一次情報)。中身は残土処分/収納の棚/大工の手間/設備グレードアップ
- **業界一般は「普通に500万円以上」。1,000万円の追加で融資が下りず親から借りる例も。**
  → **これは金融機関から聞いた伝聞。記事では必ず伝聞と明示し、本人の一次情報と混ぜない**
- 差が出るのは運用: 変更のたびに都度見積もり → 増減を確認してから工事 →
  溜まったところで一度まとめる。そして**最初から予算内で設計する**
- 読者が聞くべき一言:「追加が出るときは、どういう流れで出ますか」

**坪単価で比べてはいけない理由**

- 坪単価に業界共通のルールはなく、**会社ごとに揃え方が違う**
- 坪単価 = 金額 ÷ 施工床面積 → **面積が大きいほど坪単価は安くなる**
- **工事を省けば坪単価は下がる。** 省ける例: 仮設 / 外部配管 / カーテン / 照明 / エアコン
- → 見かけ上いくらでも安くできる

**比べるときに揃えるもの**

カーテン / 照明 / エアコン / 外構費 / 設備のグレード / 断熱・気密・換気・構造の性能。
理想は**同じ図面・同じ仕様・同じ工事内容**。
一般の方には難しいので、第三者の建築士にヒアリング→ラフプラン→そのプランで各社に見積依頼、という手がある
(伴走サポートのサービス)。**「何十倍で回収」のような倍率は書かない(2026-09-03 本人了承)。**
書くなら「1社ごとの差が数百万円になる話なので、そこにお金を払う価値があると思っています」。

**内訳をどこまで出してもらうか(線引き。記事の⑥に必ず入れる)**

- 断り文句の実例: 「システム上、出せないんです」「会社のルールで出せません」
  「うちはこの見積もり形式でやっています」
- 出ていないと困る理由: **キッチンを変更したときに、いくら上下したか判断できない**
- 出してもらうのは**変更しそうで金額の大きいものだけ**:
  キッチン / お風呂 / トイレ / 洗面化粧台 / 外壁の㎡単価
- **すべての内訳は要らない。過剰な要求はしない。**
  柱1本・合板1枚・金物1個の単価を知っても**減額対象にはしにくい**

**頼み方(記事の締めに使う)**

- 相見積もりは**隠さず正直に言う**。「それでも良ければ見積もりをしてください」とお願いする
- 仕様(断熱・気密・換気・構造・外壁)を揃えないと不公平
- **金額の安い高いだけで判断しない。** 設計担当の能力・工事の品質・現場監督は金額に出ないが重要
- 何度もやり直しをさせると相見積もりを受けてもらえなくなる。
  最初に仕様と性能を提示して「この間取りで見積もりを」と出すと**精度のいい見積もりになる**
- **人が動く以上そこには金額が発生している。それを無料でやってもらっている。**
  「お客様」ではなく**「やっていただいている」姿勢**で臨むほうが嫌われない

### 構造の用語と説明(2026-09-02 本人が直接修正。**この通りに書く**)

構造の話は、施主向けに噛み砕くときに**言い換えてはいけない用語**がある。
以下は一度こちらが間違えて、本人に直してもらったもの。

**梁の話**
- ×「梁が太くなる」 → ○「**梁成(はりせい)が大きくなる**」
  梁成 = 梁の上下方向の寸法(背の高さ)。力を遠くへ飛ばすほど大きくなる。
- 梁成が大きくなると梁が天井から下に出てくる。
  出てこないようにするには「天井が下がる」のではなく、**階高を上げる**ことになる。
  → 外壁が増え、柱も長くなり、階段の段数も変わる。**建物そのものが大きくなる。**
- つまり梁1本の話が、家全体のコストになって返ってくる。

**総2階の強さ**
- ×「四角い総2階が一番強くて一番安い」(**言い切ってはいけない**)
- ○ 安定しているのは「**正方形に近い総2階**」。
- 短辺と長辺の差が大きい細長い建物は不利。理由:
  **長い面ほど大きな力を受けるが、それを支えるのは短辺方向の壁で、細長い平面ではその壁が少ない。**
  受ける力は大きいのに支える壁が少ない、という説明で書く。

**偏心**
- 偏心とは、**重心と剛心の差**のこと。
  - 重心 = 重さの中心
  - 剛心 = 強さの中心。耐力壁が多く集まっている側に寄る
- 2つが離れているほど偏心が大きい。**剛心を軸にして回ろうとし、ねじれながら倒壊する。**
- **剛心と重心は近いほど安定する。**
- 注意喚起として必ず添える:
  **形が変わっている建物・デザイン性が高いと感じる建物ほど、ここが崩れやすい。**
  (片側だけ全面ガラス / 平面を大きく変形 / 一部を張り出す ── いずれも重心と剛心を引き離す)
- 表記は「偏心・剛心」で統一(本人は「偏芯・剛芯」と書くことがある。**本人が指定したらそちらに合わせる**)。

**書くときの原則**
構造は本人の専門領域なので、**分かりやすさのために用語を崩さない。**
用語は正確に出したうえで、その直後に一行で意味を添える形にする。
分からない挙動を推測で埋めない。**曖昧なら書く前に本人に聞く。**

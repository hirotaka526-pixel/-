## 2026年8月確認

### 建築基準法 2025年4月施行の改正

- いわゆる **4号特例の縮小**。これまで木造2階建ての確認申請で省略されていた
  構造関係規定の審査が、原則として必要になった
- 対象の区分が「新2号建築物」「新3号建築物」に再編された。一般的な木造2階建ては新2号にあたり、
  構造関係の図書提出・審査が必要。新3号(木造平屋・延べ200㎡以下)は審査省略が残る
- **必要壁量の基準も見直された。** 「軽い屋根 / 重い屋根」の区分をやめ、建物・屋根・外壁・
  太陽光発電設備などの実況に応じて必要壁量を算定する方式になった。断熱材の厚みや
  太陽光パネルで住宅が重くなったことが背景
- **注意:** 義務化されたのは構造計算書の提出と審査であって、耐震等級3にすることではない。
  建築基準法が求めるのは耐震等級1相当のレベルで、等級1の家は合法

### 耐震等級

- 耐震等級は品確法にもとづく住宅性能表示制度で **等級1・2・3の3段階**。
  「等級3相当」という区分は制度上存在しない
- 耐震等級3を出す計算方法は **性能表示計算(品確法)** と **許容応力度計算**。
  建築基準法の壁量計算だけでは等級3は取れない
- 性能表示計算より許容応力度計算のほうが検討項目が多く、必要な耐力壁の量も多くなる
- **未確認:** 「性能表示計算の等級3は強度1.9〜2.0、許容応力度計算は2.4〜2.7」という数字が
  複数の住宅会社サイトに出ているが、一次資料まで辿れていない。**記事に数字として書かない。**
  本人が根拠を持っているなら、確認した上で使う

### 地震保険・性能評価書

- 耐震等級3で **地震保険料が50%割引**(等級2は30%、等級1は10%)
- 割引を受けるには保険会社に **確認資料** の提出が必要。建設住宅性能評価書、設計住宅性能評価書、
  長期優良住宅の認定通知書＋設計内容説明書、フラット35の適合証明書など。
  **「等級3相当」では確認資料が出せないので割引を受けられない**
- 住宅性能評価書の取得費用は **10万〜40万円程度**(書類作成と申請。会社と申請先で変わる)

### 見積書の内訳(2026-09-03 本人インタビュー。**全媒体でこの数字を使う**)

30坪前後の木造2階建てが前提。**「削られやすい項目」は本人が「分からない」と回答したので書かない。**

**金額が膨らみやすい項目**

1. **地盤改良** — 間取り確定後に地盤調査 → 地耐力で工事が決まる。
   地盤の強さ / 地質 / 家の大きさで変わる。**契約時点では誰にも金額が分からない。**
   金額は 数十万円〜200万円(既出)。上限の目安だけ先に聞く
2. **基礎工事の残土処分** — 家の大きさ、既存地面の高さと設計地盤面の設定で変わる。
   **土は掘ると体積が増える**ので、見積の数量は掘る前の体積より多めに計上される(水増しではない)
3. **外壁** — 面積が大きいので、㎡単価の差が積み上がる。**㎡単価を出してもらう価値がある**
4. **窓(サッシ)** ★本人の一番の主張
   - 多くの会社が樹脂サッシ＋トリプル。**掃き出しのような大きな窓では非常に高い**
   - 大きな窓は南側にある → 枠の太い樹脂サッシ＋トリプルだと**冬の日射取得熱が使えない**
   - 高い金額を払っているのに省エネ効果が出ない。掃き出しは**開閉が重たい**
   - 本人の推奨: 南側=アルミ樹脂複合＋ペアガラス / その他=樹脂サッシ / 余裕があればトリプル
   - アルミ樹脂複合を南に使う理由: 枠が細くガラス面積が大きい / 冬の日射取得で暖房費が下がる /
     アルミ枠で軽く掃き出しに向く。外がアルミ、中が樹脂
5. **住宅設備** — **グレード1段階で20〜30万円。表面の仕上げ材(面材)でさらに10〜15万円。**
   キッチンは 高性能IH / フロントオープン食洗機 / 浄水器付き水栓 で積み上がる。
   **トイレ: タンクレス30〜40万円、タンク付き10〜15万円。使い勝手はほとんど変わらない**
6. **内装の壁の仕上げ** — エコカラットやタイルで上がる。
   代案: **外壁用のサイディングを内装に貼る**と質感が出てコストダウンになる

**「一式」で後から追加が出やすい項目(金額の大きい順)**

1. **付帯工事 一式** — 定義がなく中身が会社ごとにバラバラ(屋外給排水を含む会社もある)。
   明細が曖昧なまま**一式300万/400万**の決め打ちが多い。
   **家を小さくしても金額が変わらない** → 小さい家ほど総額に対する重みが大きい
2. **電気工事 一式** — 位置移動・追加という小さな追加が積み重なる。
   スイッチ/コンセントの形状は1つは小さいが**数が多い**。照明1つ増やすと配線とスイッチが要る
3. **内装工事 一式** — 床材と壁天井クロスだけのことが多い。**カーテンとカーテンレールが入っていない**
4. **外構工事 一式** — 境界ブロック・フェンス・造成まで含むことも。造成と外構をまとめる会社もある。
   駐車場(コンクリート/砂利)、アプローチ(コンクリート/レンガ/枕木)、
   **機能門柱 普通20〜30万円・いいもの50〜60万円**、フェンス(高さ・種類で変わる。
   **境界60mならm単価が小さくても大きな金額**)。→ メーカー・商品・品番・単価まで聞く

**契約後の追加工事**

- **インザホームは100万円前後まで**(一次情報)。中身は残土処分/収納の棚/大工の手間/設備グレードアップ
- **業界一般は「普通に500万円以上」。1,000万円の追加で融資が下りず親から借りる例も。**
  → **これは金融機関から聞いた伝聞。記事では必ず伝聞と明示し、本人の一次情報と混ぜない**
- 差が出るのは運用: 変更のたびに都度見積もり → 増減を確認してから工事 →
  溜まったところで一度まとめる。そして**最初から予算内で設計する**
- 読者が聞くべき一言:「追加が出るときは、どういう流れで出ますか」

**坪単価で比べてはいけない理由**

- 坪単価に業界共通のルールはなく、**会社ごとに揃え方が違う**
- 坪単価 = 金額 ÷ 施工床面積 → **面積が大きいほど坪単価は安くなる**
- **工事を省けば坪単価は下がる。** 省ける例: 仮設 / 外部配管 / カーテン / 照明 / エアコン
- → 見かけ上いくらでも安くできる

**比べるときに揃えるもの**

カーテン / 照明 / エアコン / 外構費 / 設備のグレード / 断熱・気密・換気・構造の性能。
理想は**同じ図面・同じ仕様・同じ工事内容**。
一般の方には難しいので、第三者の建築士にヒアリング→ラフプラン→そのプランで各社に見積依頼、という手がある
(伴走サポートのサービス)。**「何十倍で回収」のような倍率は書かない(2026-09-03 本人了承)。**
書くなら「1社ごとの差が数百万円になる話なので、そこにお金を払う価値があると思っています」。

**内訳をどこまで出してもらうか(線引き。記事の⑥に必ず入れる)**

- 断り文句の実例: 「システム上、出せないんです」「会社のルールで出せません」
  「うちはこの見積もり形式でやっています」
- 出ていないと困る理由: **キッチンを変更したときに、いくら上下したか判断できない**
- 出してもらうのは**変更しそうで金額の大きいものだけ**:
  キッチン / お風呂 / トイレ / 洗面化粧台 / 外壁の㎡単価
- **すべての内訳は要らない。過剰な要求はしない。**
  柱1本・合板1枚・金物1個の単価を知っても**減額対象にはしにくい**

**頼み方(記事の締めに使う)**

- 相見積もりは**隠さず正直に言う**。「それでも良ければ見積もりをしてください」とお願いする
- 仕様(断熱・気密・換気・構造・外壁)を揃えないと不公平
- **金額の安い高いだけで判断しない。** 設計担当の能力・工事の品質・現場監督は金額に出ないが重要
- 何度もやり直しをさせると相見積もりを受けてもらえなくなる。
  最初に仕様と性能を提示して「この間取りで見積もりを」と出すと**精度のいい見積もりになる**
- **人が動く以上そこには金額が発生している。それを無料でやってもらっている。**
  「お客様」ではなく**「やっていただいている」姿勢**で臨むほうが嫌われない

### 横向きの力は、地震だけではない(2026-09-07 本人確認)

構造の話で横力を説明するときは、**「地震や台風」と必ず両方書く。**

- **地震の力は、基礎から入ってくる**(地面が揺れるので、下から)
- **台風の力は、基礎より上の建物本体に直接かかる**

本人の言い方は「地震は下から揺れ、台風は上から揺れます」。
「上から」は**基礎より上という意味**であって、上空から押されるという意味ではない。
記事で使うときは、誤読されないように**「基礎より上」と補って書く。**

### 木造と鉄骨(2026-09-11 本人。**立場なので緩めない**)

- **素材として、鉄は木より高い**
- **3階建てでも、木造で耐震等級3は取れる。** 許容応力度計算できちんと組めばよい。台風も同様
- それでも心配なら**制震装置で補強**できる。**そこまでやっても、まだ鉄骨のほうが高い**
- 「木造だから弱い、鉄骨だから強い」は**間違い**
- **「地震に強くしたいから鉄骨一択」という考え方は、コストの面から見て間違っている**
- 木造のほうが**設計の自由度が高い**

**木造で判断できる条件**(2026-09-06の相談で本人が木造可と判断した根拠)
- **間口がそれほど広くない**
- **大きな空間がない**
→ この形なら木造で十分に耐震性のある3階建てが建つ

**ただし選べないことがある**
- 大手ハウスメーカーは**構造体がもう決まっている**
- **会社を選ぶことが、そのまま構造を選ぶことになる**
- だから読者に渡すセリフは「契約前」ではなく**「会社を決める前」**:
  「この規模なら、他にどんな構造が選べますか。それぞれいくら違いますか」

### 大手の「◯年保証」の仕組み(2026-09-11 本人)

- 大手は保証期間の長さを売りにする(例: 60年保証)
- **放っておいて続くものではない。10年ごとに決められた工事をしないと保証は延長されない**
- **15年持つ部材でも、次の10年の保証を取るために10年の時点で工事することになる**
- → **保証を維持するコストが、住んでいる間ずっとかかり続ける。生涯コストは高くなる方向**
- 批判ではなく仕組みの説明として書く。読者に渡すセリフ:
  「保証を延長するために必要な工事は、10年ごとにいくらかかりますか」

※これは**長期優良住宅の点検義務とは別の話。** 混同しない。
長期優良住宅のほうは「耐震等級3の認定が付く / 地震保険が半額」が本人の採用理由。

### 営業マンが施主の要望どおりに描く理由(2026-09-11 本人。業界の内部の話)

- 初めて家を建てる人が間取りを考えるのは**ものすごく難しい**。だから本来は聞く側が引き出す
- ところが営業する側は、**言われたとおりに描いたほうが都合がいい**
  - トラブルにならない
  - **責任が施主側に移る**(「お客様のご要望どおりに作りました」で終われる)
- だから**新たな提案もしないし、深いヒアリングもしない**
- その結果、**建って住んでから初めて「使いにくい」に気づく**
- 書くときの立ち位置: **施主が悪いのではない。**
  要望を出すのは施主の仕事だが、**その要望が暮らしとして成り立つかを確かめるのは描く側の仕事**

### 間取りを変えると金額が上がる理由(2026-09-11 本人)

- 減額は「**量を減らす**」か「**グレードを下げる**」の2つしかない
- 間取りを変えても、量もグレードも変わらない。**変わるのは位置だけ**
- 位置が変われば**設計も構造も変わる** → 手間が増える → 金額になって返ってくる
- ※「配管も電気も動く」は初稿でこちらが足した説明。**本人の説明は「設計も構造も変わる」。**
  そちらを使う

### 構造の用語と説明(2026-09-02 本人が直接修正。**この通りに書く**)

構造の話は、施主向けに噛み砕くときに**言い換えてはいけない用語**がある。
以下は一度こちらが間違えて、本人に直してもらったもの。

**梁の話**
- ×「梁が太くなる」 → ○「**梁成(はりせい)が大きくなる**」
  梁成 = 梁の上下方向の寸法(背の高さ)。力を遠くへ飛ばすほど大きくなる。
- 梁成が大きくなると梁が天井から下に出てくる。
  出てこないようにするには「天井が下がる」のではなく、**階高を上げる**ことになる。
  → 外壁が増え、柱も長くなり、階段の段数も変わる。**建物そのものが大きくなる。**
- つまり梁1本の話が、家全体のコストになって返ってくる。

**総2階の強さ**
- ×「四角い総2階が一番強くて一番安い」(**言い切ってはいけない**)
- ○ 安定しているのは「**正方形に近い総2階**」。
- 短辺と長辺の差が大きい細長い建物は不利。理由:
  **長い面ほど大きな力を受けるが、それを支えるのは短辺方向の壁で、細長い平面ではその壁が少ない。**
  受ける力は大きいのに支える壁が少ない、という説明で書く。

**偏心**
- 偏心とは、**重心と剛心の差**のこと。
  - 重心 = 重さの中心
  - 剛心 = 強さの中心。耐力壁が多く集まっている側に寄る
- 2つが離れているほど偏心が大きい。**剛心を軸にして回ろうとし、ねじれながら倒壊する。**
- **剛心と重心は近いほど安定する。**
- 注意喚起として必ず添える:
  **形が変わっている建物・デザイン性が高いと感じる建物ほど、ここが崩れやすい。**
  (片側だけ全面ガラス / 平面を大きく変形 / 一部を張り出す ── いずれも重心と剛心を引き離す)
- 表記は「偏心・剛心」で統一(本人は「偏芯・剛芯」と書くことがある。**本人が指定したらそちらに合わせる**)。

**書くときの原則**
構造は本人の専門領域なので、**分かりやすさのために用語を崩さない。**
用語は正確に出したうえで、その直後に一行で意味を添える形にする。
分からない挙動を推測で埋めない。**曖昧なら書く前に本人に聞く。**

## 擁壁のある土地(2026-09-13 本人インタビュー。**全媒体でこの内容を使う**)

### 大前提

**高低差2m・3mのある土地は、原則として選ばない。** 理由は資産価値。
鉄筋コンクリート造できちんとつくっても**擁壁自体が劣化する**ので長く住み続けられず、
何十年か経って更地にして売ろうとしても**買い手がいない=売れない土地**になる。

### 現地で最初に見るのは「何でできているか」(構造)

**やめたほうがいい擁壁**

- **普通のコンクリートブロックで土留めしている** —— 鉄筋が少なく、そもそも**塀に使う材料**で
  土圧をかけられない。土留めに使うなら**CPブロック**という専用のものがある(**表記はCPブロック**)。
  施工方法も強度もまったく違うので、**ここで見分けがつく**
- **二段積み** —— 下が**間知ブロック**、上がコンクリートブロック。この地域で多い。
  買うなら**今の基準に合った土留めにやり替える**か、**高さの2倍以上建物を離す**かの二択。
  後者は現実的でない
- **水抜き穴がない / 詰まっている** —— 土圧に加えて**雨のときの水圧**がかかり、
  擁壁が**外側にふくらむ**。古い擁壁でよく起きる
- **2ミリを超える幅で、斜めに入ったひび** —— **不同沈下**の可能性。本人は土地選びで選ばない
- **擁壁の下の地盤が弱い** —— 見た目では分からない。**住宅会社に聞く**

**線引き:髪の毛ぐらいの細いひびは気にしなくてよい。** コンクリートに小さなクラックは入るもの。

**安心できる擁壁** —— 工事履歴・仕様書・設計概要書が残っている / 築年数が新しい /
ひび割れがない / 水抜き穴があり実際に水が流れる / 擁壁の下の地盤がよい。
鉄筋コンクリート造の耐久年数は一般に60年と言われるが、擁壁は**常に土圧がかかり土中の水分にも触れる**ので
**劣化は早いと理解しておく。**

### がけ条例(2026-09-14 WebSearchで裏取り済み)

**愛知県建築基準条例 第8条。** 高さ**2mを超える**がけに接する・近接する敷地では、
**がけの上ならがけの下端から、がけの下ならがけの上端から、がけの高さの2倍以上**の水平距離をあける。
堅固な地盤または特殊な構造方法で知事が定める場合は除く。
高さ2mを超えるがけの上の敷地には**排水施設**が必要。
**「2m以上」ではなく「2mを超える」。** 都道府県ごとに条例が違うので、記事では時点と地域を書く。
出典: https://www.pref.aichi.jp/uploaded/attachment/556221.pdf

### 名古屋式L型擁壁(本人が採用)

- 高さによって仕様が変わる
- **前面と背面のダブル配筋**
- **D13(13ミリ)を100ミリピッチ**
- コンクリートブロックとは比べものにならない鉄筋量。**それだけ土圧は強い**

### 擁壁工事の金額は、先に決められない

**擁壁そのものより、まわりの条件で決まる。**

- **隣の家が近い** → 深く掘ると隣が崩れる・隣の擁壁を壊す → **仮設の土留め**が必要。ここが高い
- **掘った土の置き場がない**
- **前面道路が狭く、重機や大きなダンプが入らない** → 搬出の仮設
- 条件が悪いと、**既存擁壁の解体とやり直しだけで1,000万円になることもある**
- **1,000万円以上かかるリスクのある土地は買わないほうが賢い**(本人の判断)
- 見た目の高さと長さだけの概算は当たらない。**現地を住宅会社に見てもらってから判断する**

**跳ね上がる条件** —— 重機・ダンプが入らない / 隣に建物(塀・庭・埋設配管も崩れる) /
**開発許可が必要**(申請に半年〜1年、**書類費と設計費だけで100万円ほど**)

**擁壁以外に必ず乗るもの** —— 残土処分 / **深基礎** / 仮設 / 測量・申請 / 土留めの設計 /
**地盤改良**(擁壁の裏に入れた土は強度がないため) /
**道路側に擁壁があれば階段** / **雨水を流す配管を擁壁に貫通させる工事**

### 擁壁は、土地を狭くする(本人の一番強い論点)

- **高低差1m未満**なら土留めの費用は比較的安く、**CPブロックでの土留めもできる**
- ただし**擁壁のベースの上に建物を載せない**こと。
  擁壁の土留めは**建物の荷重がかかる計算をしていない**し、ベースの上は**埋め戻した土**で強度がない
  (載せるなら十分な突き固めや改良が必要)
- **高低差があるほどベースの幅が大きくなる** → **境界から家を離して建てる**ことになる
  → **建築面積が少なくなる**
- **だから高低差の少ない土地がよい**

### 擁壁の上と下

- **どちらが安心ということはない**(がけ条例も上下の両方に距離の規定がある)
- 逆に言えば、**自分の土地に高低差がなくても、隣の敷地が高ければその擁壁が古い場合に倒壊リスクがある**
- **水下の敷地**は雨水が流れ込みやすい。**水はけの検討**が要る

### 相場より安い土地

**それなりの理由がある。** ①相場では売れないので安い ②すぐ現金が欲しくて売主が安くしている、のどちらか。
**販売期間が長ければ売れていない土地。** 原因は擁壁だけとは限らない
(匂い / 車の音 / 近所 / 前面道路が狭い / 家が建てられない理由がある / 建築許可が必要)。
**現地に行く。建築士に同行してもらう。**

### 誰に聞くか

- 不動産屋には4点を聞く —— いつ誰がつくったか / 工事履歴と図面 / 検査済証・開発許可 / 誰の所有か。
  できれば擁壁の下の地盤と強度も

## 気密とC値(2026-10-29 本人インタビュー＋HP記事＋リール台本6本。**全媒体でこの内容を使う**)

### 中心主張

### 制度の経緯(裏取り済み)

- **1999年の次世代省エネ基準**: 地域区分に応じて**寒冷地C値2.0以下 / その他5.0以下**
- **2009年の告示改正で削除。** 理由は「多様な方法で気密性を確保できるようになったため」
- 以後、**建築基準法にも省エネ基準にも気密の義務はない**
- **2025年4月の省エネ基準適合義務化は断熱等級4＋一次エネ等級4。気密は入っていない**
- → **断熱には最低ラインがあり、気密にはない**

### C値(本人の基準)

- **1㎡あたり何㎠の隙間があるか。** 小さいほどよい

## 太陽光(2026-10-21〜22 本人インタビュー。**全媒体でこの内容を使う**)

### 書いてはいけない数字(2026-10-23 本人が却下)

記事の例としてこちらが置いた数字が、**本人に却下された。二度と使わない。**

- ✗ **「6kWで1日20kWh発電」** → 「シミュレーションによって違うので採用しない方がいい」
- ✗ **「自家消費8kWh」** → 同上(暮らし方で変わる)
- ✗ **「買う電気が1kWhあたり30円」** → 「**30円はちょっと高すぎる**」

**発電量・自家消費量・買電単価は、記事に書かない。**
自家消費が有利だと示すときは、金額を作らず
**「売る電気の単価より、買う電気の単価のほうがずっと高い」**と方向だけ書く。

### 中心主張

太陽光は**載せるか載せないかの話ではなく、基本設計の段階から考えているかの話**。
後から足すと条件を満たさない設計になり**発電効率が悪くなる**。**土地選びでも同じ**。

**「どれか満たしていないとダメ」という条件表ではない。** 基本設計から検討しているかを問う。

### 後から足した家で実際に起きたこと

- 日当たりの悪い土地を買ってしまった
- **後から壁に穴をあけたので気密が悪くなった**
- **黒いパネルで、こだわった屋根の色が黒くなり見た目が悪くなった**
- **施工管理が悪くパネル裏に鳩が巣をつくり、撤去＋侵入防止パネルで40万円。売電利益が一気に消えた**

### 基本設計から考えると

発電効率がよくなる / **土地選びが変わる** / 屋根のデザインと売電を両方検討して納得して建てられる /
**壁貫通部に気密処理ができるので結露の心配がない** /
**全体の予算に組み込めるので、安い住宅ローンで払える**

### 土地選びの段階で見ること

- **屋根に太陽が当たる敷地を選ぶ**
- **屋根が建物や樹木で日陰にならないか**
- **道路から見た外観と、屋根勾配やパネル配置のバランス**(道路からの視線)

### 価格(2026-10時点の相場。本人)

- **パネル 1kWあたり30万円**
- **足場 15万〜20万円**(立地条件や屋根形状で変わる)
- **蓄電池 5kWhで70万円 / 10kWhで150万円**
- ここに**諸経費・現場管理費・申請費**が乗る
- **メーカーによって価格は大きく違う。** 需要が増えればもう少し下がる。
  メリデメは比較するメーカーごとに個別に調べてもらう

### 蓄電池の実力(誤解を解く。必ず書く)

- **5kWhで一般家庭の半日程度の使用量**
- **蓄電池で何日も不自由なく生活できるわけではない**
- 緊急用なら**キャンプで使えるポータブル充電器**で、携帯の充電やライトくらいは十分
- **20年くらいが寿命**と言われる

### なぜ6kW以上か

- **ZEHやGX志向型住宅の計算をすると、生産エネルギーが足りなくなる**
- **3kW程度では役に立たない**
- **6kWで屋根の面積は12坪ほど＝屋根のほぼ全面**
- **補助金を使うなら新築時に工事したほうが得。** この手の補助金は毎年国から出るが、
  **後付けの太陽光では使えない**

### 売電価格(2026-10-22 一次情報で裏取り済み)

**2026年度 10kW未満:1〜4年目 24円/kWh、5〜10年目 8.3円/kWh**
2025年10月開始の**初期投資支援スキーム**による階段型。投資回収を早める狙い。
出典: 資源エネルギー庁「FIT・FIP制度ガイドブック」
https://www.enecho.meti.go.jp/category/saving_and_new/saiene/data/kaitori/2026_fit_fip_guidebook.pdf
経産省 調達価格等算定委員会 https://www.meti.go.jp/shingikai/santeii/pdf/114_b01_00.pdf

**リール台本の「42円→今は10円台」は古い。** 制度が変わっているので以後は上の数字を使う。
**5年目から8.3円になる=制度の形そのものが「売って儲ける」前提をやめさせている**という読み方をする。
→ **「売って儲ける設備」ではなく「買う電気を減らす設備」**

### メーカーのシミュレーション

**発電効率のよい条件で計算してくる。** 実際は天気・パネルの汚れ・影などで
**シミュレーションどおりにはならない**。売電単価も下がるので試算どおりにはいかない。

### 将来出ていくもの

- **パワコンは10〜15年で1回交換**
- **パネルの発電効率は少しずつ下がる**(工業製品である以上仕方ない)
- **取り付けのアングルやボルトも劣化する。雨漏れの可能性**

- **後工事でのパネル固定金具からの雨漏れ工事は、保証ができないケースがほとんど**
- **撤去費用は一概に言えない。** 大量に廃棄処理された事例がまだないため。
  ただし**産業廃棄物の処理費用は毎年上がっている**ので、
  メンテナンスが必要になる**20年後くらい**に処分すれば今より高い

### 2030年問題(リール台本)

- **2030年代後半には年間50万トンの廃棄**。リサイクル体制が不十分で処分場不足・処分費増が心配
- 本当に怖いのは**発電しなくなったパネルを屋根に放置すること**
- 20〜30年で**パネル本体だけでなく固定金具やボルトも劣化**
- 台風で**重さ20キロ前後のパネル**が飛ぶ可能性。隣家の窓・車・人に当たれば
  **責任は基本的に持ち主**

### 30年で元が取れるのか(本人の答え)

**トントンになればいい。そして、損得では考えないほうがいい。**

### 住宅ローンとリフォームローンの差(記事の金額パートの核)

- 工事費そのものは新築時でも後付けでもそれほど変わらない(足場の分くらい)
- **変わるのは払い方。** 新築時は住宅ローンに入る。後付けは現金かリフォームローン
- **300万円・金利1%・35年 → 月8,600円**
- **300万円・リフォームローン10年 → 月26,300円**
- **こちらで検算したところ、どちらも金利1%での数字。差は金利ではなく期間**
- **総額の利息は10年のほうが少ない**(35年で約361万、10年で約315万)ので、
  **「総額が安くなる」とは書けない**
- 書けるのは本人の言葉のまま ——
  **「工事を決断する時期を変えるだけで、売電での手残りが大きく変わる」**
  (月1万円前後の手残りなら、35年は毎月プラス、10年は毎月マイナスから始まる)
- 実際には**リフォームローンの金利は住宅ローンよりかなり高い**ので差はさらに開く

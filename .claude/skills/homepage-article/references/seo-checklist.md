# SEO納品セットの型

記事を書き始める前にこのファイルを読む。各パーツの文字数と書き方の型をここに固定してある。

---

## 1. titleタグ(32文字前後)

記事のH1見出しとは**別物**。検索結果に表示される1行なので、H1をそのまま流用しない。
Googleは全角30〜32文字程度で切る。長いと「…」で切られてクリック率が落ちる。

**型:**

```
[主軸キーワード] + [地域名] + [数字 or ベネフィット]
```

- 主軸キーワードは **できるだけ前半** に置く
- 地域名は「高浜市」または「西三河」。両方入れると長くなるので片方
- 数字(「10の質問」「5つの後悔」)はクリック率を上げる
- 「｜インザホーム」は約8文字使う。32文字に収まらないなら入れない。
  ブランド名で検索されている段階ではないので、優先度は低い

**例:**

| 良い例 | 文字数 | 評価 |
|--------|--------|------|
| 高浜市で注文住宅｜1級建築士が教える会社選び10の質問 | 27字 | 主軸+地域+数字。◎ |
| C値とは？高浜市の1級建築士が気密測定の基準を解説 | 25字 | 疑問形+地域+専門性。◎ |
| 住宅会社の選び方チェックリスト｜契約前に必ず聞いてほしい10の質問 | 32字 | 地域名なし。全国区で戦うことになるので△ |

**避けること:** キーワードの羅列(「注文住宅 高浜市 刈谷市 碧南市 工務店」)、
記事内容と合っていない煽り、他社名の使用。

---

## 2. meta description(120文字前後)

順位には直接影響しないが、**クリック率に効く**。スマホでは短く切られるので、
大事なことは前半80文字に入れる。

**型:**

```
[読者の悩みの言語化(1文)] + [この記事で分かること(1文)] + [誰が書いているか(1文)]
```

主軸キーワードを自然に1〜2回含める。詰め込まない。

**例:**

```
「気密測定はやっていますか?」— この一言で住宅会社の実力が分かります。C値の基準、
実測値の見方、高浜市周辺で確認すべきポイントを、設計から現場管理まで手がける1級建築士が解説します。
```
(112字)

## 3. URLスラッグ

- 半角英小文字とハイフンのみ。3〜5語
- 日本語URLにしない(SNSでシェアされたときにエンコードされて崩れる)
- 記事の主題が英語で分かる形にする

| 記事 | スラッグ |
|------|----------|
| C値と気密測定の解説 | `kimitsu-cvalue-kijun` |
| 住宅会社の選び方 | `jutaku-gaisha-erabikata` |
| 高浜市の土地探し | `takahama-tochisagashi` |
| 間取りの後悔ポイント | `madori-koukai` |

**避けること:** 日付を入れる(`2026-08-column`)、意味のない連番(`column-12`)、長すぎる(6語以上)。

---

## 4. 内部リンク設計

発リンク **3〜5本**。多すぎると分散する。

**ルール:**

- アンカーテキストは「こちら」「詳しくはこの記事」ではなく、**リンク先の内容が分かる文言**にする
  - ✗ 間取りについては[こちら](...)
  - ○ 間取りの決め方は[家づくりで失敗しないための間取りの考え方](...)で詳しく解説しています
- 本文の流れの中に自然に置く。記事末に列挙するだけにしない(末尾の「関連記事」は別枠でOK)
- **まだ存在しない記事へのリンクを提案するときは、必ず「未作成」と明記する。**
  リンク切れは順位にもユーザー体験にも悪影響

**既知の既存ページ:**

| ページ | URL |
|--------|-----|
| 家づくりの想い | `/about/` |
| in the homeについて | `/in-the-home/` |
| 間取りの考え方(コラム) | `/column/madorinokanngaekata/` |
| ブログ一覧 | `/blog/` |
| お知らせ | `/news/` |

※ サイト全体の記事一覧は環境のネットワーク制限で取得できていない。他にも既存記事がある可能性が高いので、
**内部リンク案を出したら「既存記事との重複・リンク先の実在を確認してください」とチャットで伝える。**

## 5. FAQPage構造化データ

記事内のH3質問文から **3〜6問** 抜き出してJSON-LDにする。そのままコピペできる形で渡す。

**絶対のルール: 本文に書いていないQ&Aを構造化データに入れない。** Googleのガイドライン違反で、
リッチリザルトが出なくなるどころかペナルティ対象になる。

**雛形:**

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "ここに質問文(本文のH3をそのまま)",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "ここに回答(本文の該当箇所を100〜200字に要約。本文と矛盾させない)"
      }
    }
  ]
}
</script>
```

回答テキストにHTMLタグを入れる場合は `<p>` `<br>` `<ul>` `<li>` `<a>` のみ使用可。

**あわせて検討:** 記事本文には `Article` (または `BlogPosting`) schema、
会社情報ページには `LocalBusiness` schema が有効。特に `LocalBusiness` は
高浜市周辺のローカル検索に効くので、サイト側に入っていなければチャットで提案する。

## 6. 目次(TOC)

- H2/H3の階層で提示する
- 目次はリード直後、最初のH2の前に置く
- WordPressのプラグイン(Rich Table of Contentsなど)で自動生成する場合でも、
  **見出し自体が目次として読めるか**を原稿側で確認する。「はじめに」「まとめ」だけの目次は価値がない

---

## 7. 画像指示とalt

**3〜5枚。** 記事の途中に入れる位置も指定する。

- **自社の施工写真・現場写真を使う前提で指定する。** フリー素材の"それっぽい家"は
  読者に見抜かれるし、E-E-A-Tの観点でも損。撮影が必要なら「要撮影」と書く
- 図解が有効な箇所(数値の比較、構造の仕組み、フローチャート)は「図解」と指定する
- altは **画像の内容を説明する文**。キーワードを詰め込まない
  - ✗ `alt="高浜市 注文住宅 気密測定 C値 工務店"`
  - ○ `alt="高浜市の新築現場で気密測定器を使ってC値を実測している様子"`
- ファイル名も半角英小文字+ハイフンにする(`kimitsu-sokutei-genba.jpg`)

## 8. 著者プロフィールボックス(記事下に毎回入れる)

E-E-A-T(経験・専門性・権威性・信頼性)の直球。**毎回入れる。** 定型文:

```
■ この記事を書いた人

前田 浩貴(まえだ ひろき)
有限会社 IN THE HOME 代表 / 1級建築士・1級建築施工管理技士・2級土木施工管理技士

愛知県高浜市で注文住宅の設計・施工を手がける。営業任せにせず、建築士である自身が
ヒアリングから設計、現場管理までを一貫して担当。設計した人間がそのまま現場を見るため、
図面通りに建てられることを何より大切にしている。
YouTube「1級建築士 まえちゃんの家づくり教室」で家づくりの本音を発信中。

施工エリア:高浜市・碧南市・刈谷市・安城市・西尾市・知立市・岡崎市・半田市・大府市・
東浦町ほか西三河/知多エリア
```

※ 資格の記載は事実確認済みのものだけ。増やさない。

## 9. SNS導線

**中盤に1か所、最後に1か所。**

中盤(記事のテーマに関係する動画へ):

```
この話は、YouTubeでも実際の現場を見せながら解説しています。
▶ [動画タイトル](該当動画のURL)
```

動画が特定できない場合は `[該当動画のURLを入れてください]` とプレースホルダーにして、
チャットで「ここに入れる動画を選んでください」と伝える。**存在しない動画タイトルを書かない。**

最後(プロフィールボックスの下):

```
家づくりの本音や現場の様子は、YouTube・Instagramでも毎週発信しています。

▶ YouTube「1級建築士 まえちゃんの家づくり教室」
　 https://www.youtube.com/@inthehome
▶ Instagram @in.the.home
　 https://www.instagram.com/in.the.home/
```

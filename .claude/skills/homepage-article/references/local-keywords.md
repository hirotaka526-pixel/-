# ローカルキーワード設計と記事ネタ

## 大前提: 全国区キーワードで戦わない

「注文住宅 費用」「住宅会社 選び方」「間取り 後悔」といった全国区のキーワードは、
SUUMO・LIFULL HOME'S・ハウスメーカー各社が上位を固めている。地域工務店のドメインで
正面から取りに行っても届かないし、仮に流入しても商圏外の人ばかりで問い合わせにならない。

**狙うのは次の2方向だけ。**

---

## 方向1: ローカル修飾(地域名 × テーマ)

競合が一気に減り、来る人が実際の商圏の人になる。**問い合わせに直結するのはこちら。**

### 地域名の組み合わせ方

| 使う場面 | 表記 |
|----------|------|
| 主軸(本拠地) | 高浜市 / 愛知県高浜市 |
| 近隣(記事ごとに2〜4市町を選ぶ) | 碧南市、刈谷市、安城市、西尾市、知立市、半田市、大府市、東浦町、岡崎市、豊明市 |
| エリア呼称 | 西三河、知多半島、知多エリア |
| 施工エリア全体(記事末にまとめて) | 高浜市・碧南市・刈谷市・安城市・西尾市・知立市・岡崎市・豊明市・大府市・東海市・知多市・常滑市・半田市・阿久比町・武豊町・東浦町・美浜町・南知多町 |

### 掛け合わせるテーマ

```
[地域名] × [注文住宅 / 工務店 / 平屋 / 土地探し / 相場 / 坪単価 / 建築士 /
           高気密高断熱 / 耐震 / 補助金 / 会社選び / 見学会]
```

**例:** 「高浜市 注文住宅 相場」「碧南市 平屋 工務店」「刈谷市 高気密高断熱」
「西三河 建築士 設計事務所 家」「知多 土地探し 注文住宅」

### 地域記事で必ず書くこと(これが無いと"地域名を入れただけ"になって効かない)

- **西三河・知多の地盤**(埋立地・干拓地・軟弱地盤のエリア差、地盤改良の実際の頻度と費用感)
- **気候**(夏の暑さ、伊勢湾からの風、冬の底冷え、塩害)
- **土地相場と土地の探し方**(市ごとの傾向、農地転用、分家住宅)
- **自治体の制度**(高浜市・碧南市などの住宅取得補助、子育て世帯向け支援 ※制度は必ず最新を確認)
- **実際の施工事例**(◯◯市の30坪の家、など)

## 方向2: ロングテール(悩みの言語化)

競合が薄く、悩んでいる人がピンポイントで来る。**認知と信頼の獲得に効くのはこちら。**
地域名を入れなくても勝てることがある。

### 有望なネタ(競合が薄く、実務者にしか書けないもの)

**住宅性能**
- 耐震等級3「相当」と本物の違い / 壁量計算と許容応力度計算の違い
- C値に国の基準がない理由 / 気密測定を全棟やる会社とやらない会社
- UA値と実際の光熱費 / 断熱等級4が最低ラインになった意味
- 2025年4月の省エネ基準適合義務化・4号特例縮小で何が変わったか

**間取り**
- 間取りの後悔ランキングと、設計段階での防ぎ方
- 平屋が高くなる本当の理由 / 30坪で広く見せる方法
- 収納は量より位置 / 洗濯動線の作り方
- 窓の数と大きさを減らすと快適になる理由

**お金・契約**
- 見積書の「一式」と「別途工事」の見抜き方
- 坪単価の計算方法が会社によって違う話
- 地盤改良費を契約前に見積もる方法
- 住宅完成保証(任意)と瑕疵担保責任保険(義務)の違い
- 建設業許可がなくても家は建てられる話

**会社選び・進め方**
- 建築士が設計する会社と営業が間取りを描く会社の違い
- 現場監督が1人で何棟持っているかを聞く理由
- 設計と施工が分かれている場合のリスク
- 契約前に見せてもらうべき図面

## ハブ&スポーク設計

**まとめ記事(ハブ)** を1本置き、その中の各項目から **個別記事(スポーク)** へ内部リンクを張る。
サイト全体で「家づくりの判断基準」というテーマの塊ができて、ドメイン全体の評価が上がる。

```
【ハブ】住宅会社の選び方チェックリスト(公開済)
  ├─ 耐震等級3の壁量計算と許容応力度計算の違い
  ├─ C値と気密測定の話
  ├─ 見積書の「一式」と「別途工事」
  ├─ 住宅完成保証と瑕疵担保責任保険
  └─ 現場監督の担当棟数

【ハブ】高浜市・西三河で注文住宅を建てるときの総まとめ(未作成)
  ├─ 高浜市の土地相場と探し方
  ├─ 西三河の地盤と地盤改良費
  ├─ 夏の暑さに効く断熱の考え方
  └─ 高浜市周辺で使える補助金(年度ごとに更新)
```

新しい記事を書くときは、**どのハブにぶら下がるスポークなのか**を必ず決めてから書く。
どこにもつながらない単発記事は増やさない。

## 競合調査の手順(検索ボリュームツールが無い環境での代替)

1. WebSearch で主軸キーワードをそのまま検索する
2. 上位10件の内訳を見る
   - **全国ポータル・大手HMで埋まっている → そのキーワードは捨てる。** ローカル修飾かロングテールに逃がす
   - 個人ブログや地域工務店が混ざっている → 勝負になる
3. 上位記事のタイトルと見出しを見て、**書かれていないこと**を探す。そこが切り口になる
4. サジェスト・関連質問の量から需要を推定する(**数字は断定しない。「推定」と明記する**)

**キーワードプランナー等の検索ボリューム数値は取得できない。数字を作らない。**
ボリュームが必要なら、まえちゃん側でGoogleキーワードプランナー/ラッコキーワードを見てもらう。

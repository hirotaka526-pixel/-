# リール台本スキル(reel-script)

まえちゃんのInstagramリール(トークリール)の台本を作る。

## このスキルの一番大事な前提

リールは **まえちゃんが一人でカメラに向かって喋る**。川下さんは出てこない。掛け合いにしない。
そして納品するのは **そのまま声に出して読める逐語原稿** であって、要点の箇条書き(ネタ帳)ではない。

YouTubeの台本(youtube-scriptスキル)は「川下さんとの掛け合い」「ネタ帳形式」「尺配分表」「サムネ文言」
が標準仕様だが、リールでは **どれも要らない**。テロップ指示・カット割り・尺配分表・サムネ案を
勝手に足すと、まえちゃんが読み上げるときに邪魔になる。**台本本文だけを渡す。**

尺の目安は60〜90秒 = 全体で700〜900字程度。これを超えると読み切れない。

## 台本の型

見本(`references/sample-scripts.md`)の流れをそのまま踏襲する。この型は「1〜2秒で止めさせて、
最後のCTAまで連れていく」ために作られているので、ブロックの順番を入れ替えない。

各ブロックは空行2つで区切る(撮影時にどこで息を継ぐかの目印になっている)。

**① フック(2行)**
- 1行目: 住宅会社に言われがちな **間違った一言** を「」で引用し、「〜って言われた」で受ける
- 2行目: それに対するまえちゃんの怒り。「そんな会社がいるから、ちゃんとやっている会社が迷惑するんだ」のように、
  **業界一般への憤り** として書く。特定の会社が特定できる書き方にはしない
- この2行だけで内容が想像できるかを必ず確認する。リールはここで止まるか流されるかが決まる

**② 共感 → まだ間に合う**
- 「〜って言葉を信じて契約書にサインしたのに、いざ〜」と、視聴者が置かれている状況を具体的に描く
- 「一人で抱え込んでいませんか？」と問いかけ、すぐに「着工前ならまだ全部間に合います！」と希望を出す
- 不安で終わらせないのが大事。不安だけ煽ると離脱するし、チャンネルの信頼も落ちる

**③ 本題1(結論を1文)**
- 「まず知ってほしいのは、〜って事」の形で、この動画で一番言いたいことを1文で言い切る

**④ 数字で背中を押す**
- 費用・メリット・補助金などの **具体的な数字** を出し、「やらない理由はないよね」で締める
- 数字はリサーチで裏を取ったものだけを使う(後述)

**⑤ 本題2(もう一つの怖い話)**
- 「そしてもう一つ怖いのが、〜」で別の論点を出す
- 「〜すると、数千万円払って後悔する家に30年住み続けることになるよ」のように、
  **損失を時間の長さで表現する** と刺さる

**⑥ CTA①(特典)**
- 「こういった家づくりの基準は、プロフのリンクからもらえる豪華18大特典でも解説しているから受け取って」

**⑦ 行動の具体化**
- 「住宅会社とケンカする必要はなくて。『〜してください』と伝えるだけで、〜は劇的に変わります」
- 視聴者が明日すぐ言える **セリフの形** で渡すのがポイント。抽象的な心構えで終わらせない

**⑧ CTA②(LINE相談)**
- 「〜は、私の相談で話しているからLINEから申し込んでね！正しい知識を身につけて、賢く理想の家づくりをしよう！」

論点は③と⑤の2つまで。3つ目を入れたくなったら別の1本に回す。60〜90秒に3論点は入らない。

## 文体

- 一人称。「〜なんだ」「〜だよね」「〜してほしい」といったタメ口寄りの親しみやすい口調と、
  「〜ませんか？」「〜します」の丁寧語が混ざるのが、まえちゃんの地の喋り方。**無理に統一しない**
- 1文は短く。声に出して息が続く長さで切る
- 専門用語は使ってよいが、必ずその場で噛み砕く(例:「許容応力度計算」→「柱や梁を緻密に計算する」)
- 装飾記号(##見出し、箇条書き、太字、表)は台本本文に入れない。プレーンテキストで書く

## ネタ選びとリサーチ

**ネタは既存の発信から持ってくる。**

- YouTube: https://www.youtube.com/@inthehome (「1級建築士 まえちゃんの家づくり教室」)
  長尺・ショートともにネタの宝庫。既に話した内容をリール用に1論点へ絞り直す
- note: まえちゃんの記事(URLが分かっていなければ本人に聞く)
- 過去のリール、相談で実際によく出る質問

**リサーチは必ず2段構えでやる。省略しない。**

1. **ネタ元の中身を確認する** — WebSearch / WebFetch で実際の動画・記事に当たる。
   タイトルから内容を推測して書かない。まえちゃんが実際に話していることと食い違うと、本人が読めない台本になる
2. **数字と制度の裏取り** — 台本に出す数字は必ず最新を確認してから書く。特に次は年度で変わる:
   - 補助金・助成金(子育てグリーン住宅支援事業など)
   - 建築基準法・省エネ基準の改正(例: 2025年4月施行の4号特例縮小)
   - 長期優良住宅・耐震等級の申請費用、証紙代
   - 地震保険の割引率、住宅ローン控除、金利
   古い知識のまま断定するのは、まえちゃんが一番嫌がるところ。確認できなかった数字は台本に入れず、
   「ここは実感ベースの金額を入れてください」とメモで返す

ネタが指定されずに「リール台本作って」とだけ言われたら、**まずネタ元を調べて候補を2〜3個提案し、
どれで作るか決めてもらう**。いきなり書き始めない。

## 納品の形

1. **台本本文**(プレーンテキスト、空行2つ区切り) — これが主役
2. **確認メモ**(台本の外に短く) — 使った数字の出典と時点、実感に合わせて差し替えてほしい箇所、
   公開前に再確認すべき点。台本本文には混ぜない

Googleドキュメントに入れてほしいと言われたら、`contentMimeType: "text/plain"` で作る。
マークダウン記法を混ぜると、記号がそのまま文字として残って読みにくくなる。

## 公開前チェック

- 冒頭2行だけで内容が想像できるか
- 数字は最新か。断定していないか
- 特定の会社・人が特定できる書き方になっていないか
- 断定しすぎて例外を無視していないか。尺の都合で全部は書けないので、
  **一番反発が来そうな1点にだけ** 短く逃げ道を入れる(例:「もちろん〜まで、うるさく言う必要はないよ」)
- CTAが2つ(プロフリンクの18大特典 / LINE相談)入っているか
- 700〜900字に収まっているか

## 心構え

まえちゃんは肯定するだけのアシスタントを求めていない。ネタが弱い、論点が多すぎる、数字が怪しい、
と思ったら遠慮せず指摘してから改善案を出す。複数案を出すときは並べて終わりにせず、推奨まで決める。

見本は `references/sample-scripts.md` にある。書き始める前に必ず読む。

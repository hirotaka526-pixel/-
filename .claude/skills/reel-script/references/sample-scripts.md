# リール台本の見本

まえちゃん本人が「この形で作ってほしい」と指定した見本。ブロックの順番、口調、CTAの位置を
ここから外さない。空行2つが撮影時の区切りになっている。

---

## 見本1: 平屋の構造計算(本人指定の原本)

```
「平屋だから構造計算はいらないよ」って言われた
そんな会社がいるから、ちゃんとやっている会社が迷惑するんだ


「平屋だから耐震も安心」「高気密高断熱ですよ」って言葉を信じて契約書にサインしたのに、いざ見積もりを見たら構造計算も気密測定も入っていない…。
「もう契約しちゃったから言えない…」って一人で抱え込んでいませんか？着工前ならまだ全部間に合います！


まず知ってほしいのは、平屋でも、柱や梁を緻密に計算する「許容応力度計算」をして、耐震等級3にしてほしいって事


これ、計算に35万円くらい、長期優良住宅の申請と証紙で71300円出せば地震保険が半額になって、今年の補助金は75万円もらえるんだ。やらない理由はないよね。


そしてもう一つ怖いのが、平屋の「夏のサウナ化」と「壁の中のカビ」。
屋根に通気層を作らない手抜き施工をされたり、工事中の気密測定をサボられると、せっかくの断熱材が全部パーになって家が腐ってしまうんだ。
住宅会社に言われるがまま流されると、数千万円払って後悔する家に30年住み続けることになるよ。


こういった家づくりの基準は、プロフのリンクからもらえる豪華18大特典でも解説しているから受け取って


住宅会社とケンカする必要はなくて。「許容応力度計算と工事中の気密測定、費用払うので追加してください」と伝えるだけで、家の性能と安心感は劇的に変わります。


工務店との上手な交渉術や図面のチェックポイントは、私の相談で話しているからLINEから申し込んでね！正しい知識を身につけて、賢く理想の家づくりをしよう！
```

### この見本から読み取るべきこと

- 冒頭2行は「会社の間違った一言」+「まえちゃんの憤り」。憤りの矛先は業界であって、特定の会社ではない
- 「〜って事」「〜だよね」「〜なんだ」と、「〜ませんか？」「〜します」が混在している。これが地の喋り方
- 数字(35万円 / 71300円 / 半額 / 75万円)を畳みかけてから「やらない理由はないよね」で決める
- 論点は2つ(構造計算・耐震等級3 / 通気層と気密測定)。3つ目はない
- 損失は「数千万円払って後悔する家に30年」と、金額×時間で表現している
- CTAは2回(プロフリンクの18大特典 → LINE相談)。間に「明日そのまま言えるセリフ」を挟んでいる
- 全体で約700字

## 見本2: 見積書の「一式」と「別途工事」(同じ型で作った例)

```
「うちは見積書、"一式"でまとめてるんですよ」って言われた
そんな会社がいるから、1行ずつ内訳を出している会社が損をするんだ


「他社さんより安いですよ」「これで全部込みです」って言葉を信じて契約書にサインしたのに、着工が始まった途端に「それは別途です」で200万円の追加…。
「もう契約しちゃったから今さら聞けない…」って一人で抱え込んでいませんか？着工前ならまだ間に合います！


まず知ってほしいのは、「一式」と書かれた行は、数量も単価も書いていない＝何がどこまで入っているのか誰にも分からない行だって事


例えば「電気工事 一式 80万円」。コンセントが何個で、照明が何台までなのかが書いてない。だから着工後に1か所追加するたびに1万円、2万円と積み上がっていくんだ。
逆に、数量と単価が入った内訳明細さえ出してもらえば、他社と1行ずつ比べられるし、要らない設備を削って減額もできる。しかも出してもらう費用は0円、頼むだけ。やらない理由はないよね。
もちろん「仮設工事 一式」「諸経費 一式」みたいに金額が小さくて中身が決まっている項目まで、うるさく言う必要はないよ。危ないのは、金額が大きいのに一式でまとめられている工事。


そしてもう一つ怖いのが、見積書の一番下に小さい字で書いてある「別途工事」。
地盤改良、外構、カーテン、照明、エアコン、給排水の引込…ここが全部別途になっていると、最終的な総額は300万、400万と平気で変わってくるんだ。安い見積書ほど、別途が多い。
住宅会社に言われるがまま流されると、数千万円払って後悔する家に30年住み続けることになるよ。


こういった家づくりの基準は、プロフのリンクからもらえる豪華18大特典でも解説しているから受け取って


住宅会社とケンカする必要はなくて。「"一式"の行を、数量と単価が入った内訳明細にしてください」「別途工事の概算も出してください」と伝えるだけで、見積書は別物になります。


見積書のチェックポイントや工務店との上手な交渉術は、私の相談で話しているからLINEから申し込んでね！正しい知識を身につけて、賢く理想の家づくりをしよう！
```

### 見本1との違い

「もちろん〜うるさく言う必要はないよ」という一文を④に足している。断定だけで押し切ると
同業から反発が来るし、視聴者にも不正確な印象を与えるテーマだったため、
**一番反発が来そうな1点にだけ** 逃げ道を作った。こういう調整はテーマに応じて判断する。
